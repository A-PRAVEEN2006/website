# PRIME X | Project Hub

Welcome to the **PRIME X** repository. This project is a sophisticated web-based platform designed to showcase and distribute a suite of advanced AI-powered mobile applications. It features a premium, cinematic user interface built with modern web technologies.

## Project Overview

PRIME X serves as a central hub for innovative software solutions. The platform focuses on high-fidelity user experiences, utilizing interactive animations and smooth transitions to engage users from the moment they land on the page.

### Key Features

- **Interactive Entrance Sequence**: A custom-animated spider sequence that leads into a cinematic "domain expansion" reveal.
- **Dynamic Dashboard**: A responsive, high-performance dashboard utilizing glassmorphism and modern UI patterns.
- **Integrated Application Gateways**: Seamless navigation to dedicated landing pages for individual applications within the PRIME X ecosystem.
- **Audio Control System**: Built-in background music management with manual play/pause controls.

## Application Suite

The platform currently hosts the following applications:

| Application | Classification | Summary |
| :--- | :--- | :--- |
| **AuraMax-Zenith** | AI Vision | Advanced facial mapping and aesthetic analysis using deep learning models. |
| **FoodLens** | Health Technology | Nutritional tracking and meal analysis powered by the Google AGI food model. |
| **PsiRa** | Secure Communications | A privacy-focused communication tool utilizing decentralized routing and advanced encryption. |

## Technical Specification

- **Build Tool**: Vite
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Animations**: CSS Keyframes & JavaScript-managed transition states
- **Responsiveness**: Mobile-optimized layouts including interactive "pull" gestures

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (Stable version recommended)
- [NPM](https://www.npmjs.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/A-PRAVEEN2006/website.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## Repository Structure

- `index.html`: The main landing and dashboard entry point.
- `main.js`: Core logic for animations, audio, and navigation state.
- `style.css`: Comprehensive design system and layout configurations.
- `auramax.html`, `foodlens.html`, `psira.html`: Individual landing pages for the suite applications.
